# MiseLab

MiseLab is the broader platform concept being developed in parallel with this
project. The current repository is a custom school order operating under the
working name **PastryCampus Calculator**. The relationship between this project
and the MiseLab platform (ownership, licensing, branding) is to be defined.

## Platform Vision

MiseLab is a mobile-first culinary calculation workspace rooted in
`mise en place`: having everything prepared, organized, measured, and ready
before work begins.

Long-term the platform covers:
- Multi-calculator modules: ice cream, sorbet, chocolate bars, molded bonbons,
  praline fillings, pizza dough, sourdough, bakery formulas
- Technical cards, costing, nutrition, report exports
- RecipeHub-style workflows: versioning, imports, collections, monetization
- Accounts, school roles, Telegram Mini App, PWA

## Brand

## Current Status

The PastryCampus Calculator MVP reuses the architecture from MiseLab but ships
under the school's working name. The codebase is kept extensible so it can
converge back into the MiseLab platform once the relationship is clear.
